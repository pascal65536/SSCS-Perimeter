# Лабораторная работа №1: Уязвимость SSTI

**Цель работы:** Научиться выявлять и устранять уязвимость Server-Side Template Injection в приложениях на Flask.

## Теоретическая справка

SSTI возникает, когда пользовательский ввод передаётся в движок шаблонов (Jinja2) без предварительной санитизации. Это позволяет атакующему внедрить собственный шаблонный код и выполнить произвольные команды на сервере.

![Схема атаки SSTI](images/ssti-diagram.png)
*Рис. 1. Схема прохождения пользовательского ввода в движок шаблонов*

## Задание

Изучите исходный код уязвимого приложения:

```python
# vulnerable_app.py
from flask import Flask, request, render_template_string

app = Flask(__name__)

@app.route('/hello')
def hello():
    name = request.args.get('name', 'Guest')
    # УЯЗВИМОСТЬ: прямая интерполяция в строку шаблона
    template = f"<h1>Hello {name}</h1>"
    return render_template_string(template)

if __name__ == '__main__':
    app.run(debug=True)
```

### Что нужно сделать

1. Запустите приложение локально.
2. Подберите полезную нагрузку (payload), которая позволит вывести содержимое переменной окружения `SECRET_KEY`.
3. Сделайте скриншот результата эксплуатации.
4. Предложите **два** варианта исправления уязвимости.
